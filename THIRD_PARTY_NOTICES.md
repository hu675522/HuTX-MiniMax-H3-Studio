# Third-party notices

The optional H3 HyperFlow bridge interoperates with:

- HyperFlow: https://github.com/Video-Rebirth/hyperflow (Apache-2.0)
- ComfyUI: https://github.com/Comfy-Org/ComfyUI

No upstream HyperFlow source file or model weight is bundled. The project contains an independently integrated compatibility bridge for public model and ComfyUI interfaces. HyperFlow weights must be supplied separately by the user.
