## 具体限制

- 本地格式校验检查非空 PCM16、采样率、声道和时长，但非空静音仍可通过，不等同于有效人声检测。
- `speech_routes.py` 只在启动前检查队列；`speech_local.py` 的锁只覆盖 TTS，未防止之后新入队的 H3 并发使用 GPU。独立 worker 回收不等于已经完成全局串行调度。
- 云端传输有 401/403/429 静态提示，但 `SpeechService.generate` 和前端 controller 最终统一为失败文案，不能算细分错误 UX 完成。
- 云端 mock 使用注入的 FakeTransport；测试名称含 official 不构成供应商支持上传协议的证据。真实付费验收按计划仍需另行授权；当前协议依据缺口应先解决。
- 语音缓存上限 8 项/30 分钟，重启失效；采用状态未约束 node execute。视频重试长期复用、时长匹配和锁定新口播是第五阶段工作，当前未实现。
- 当前预设：本地用户自建音色；云端两个系统音色。Mock 示例是测试音，不是真实音色样音。
