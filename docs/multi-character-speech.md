# 多角色口播 · 开发预览

## 深色视觉样板

多角色节点采用独立的 Framer-inspired AI 科技视觉样板：低眩光雾蓝灰画布、蓝紫环境光、半透明浅蓝大圆角卡片、深色高对比文字和蓝紫渐变主操作。只参考其配色与空间语言，不使用 Framer 标识、素材或组件代码；单人口播、Local、Cloud 暂不换肤。说明收在顶部帮助入口。音频区使用紧凑播放控件，继续复用原 audio 元素和 URL，提供播放、暂停、静音及进度显示；跳转只在浏览器报告可 seek 时启用，不修改后端音频接口。

Edge mock 已验证六种节点宽度、音频操作、独立生成/采用、三路接线和刷新恢复；原单人口播面板回归通过。未调用真实 TTS。

新增 `HuTX · 多角色口播`（`GHMultiSpeechInputGH`）。现有单人口播节点不变。

## 使用

1. 共用顶部执行端：本地 CosyVoice / 百炼云端。云端复用原语音凭证模块，不使用 Prompt Optimizer 的凭证。
2. A/B/C 三张角色卡默认展开；分别填写角色名、参考声线或预设音色、新台词、语速。角色名仅用于展示。
3. 可以逐卡生成、取消、试听并采用；“生成待更新角色”按 A/B/C 串行执行，只生成有台词且未生成或已修改的角色。失败或取消会停止本轮批量。
4. “采用全部已生成结果”只采用已有成功结果，不生成新音频。也可以分别采用。
5. 固定输出 `audio_A / audio_B / audio_C` 分别连到 Local 的 `reference_audio_1 / reference_audio_2 / reference_audio_3`。
6. Local 选择全能参考和匹配的 Ref2VA 主模型，添加图片或视频。对应音频槽显示可试听的已采用音频，Prompt 输入 `@` 可选择插入已有 canonical 标签。

## 身份、保存与兼容

- 三个物理输入槽固定。停用 B 后 C 仍在 `ref_audio_3`；显示的 `<Audio N>` 继续按现有 active-order 规则计算，参考视频原声也参与编号。不要把角色字母直接当作 canonical 数字。
- 原 Prompt 中的标签不会因停用、改名或移除接线而被重写；现有验证继续处理失效标签。更改音频组合后应检查 Prompt 的对应关系。
- 工作流只保存公开角色参数、输入文件相对路径、已采用快照路径和折叠状态；不保存 API Key 或凭证对象。用户名下的 WAV/快照仍在本机 input，分享 workflow 不等于分享这些文件。
- Queue 不触发 TTS。非空且启用的角色必须有与当前参数匹配的采用快照；缺失或修改后明确报错。空台词或停用角色输出 None，下游对应可选槽忽略它。
- 多角色输入使用已有 `reference_only` 模式，不自动拼接、排时间线、安排三人轮流说话或锁定三条声轨。实际画面与口型仍需模型实测。
- 旧 `driver_audio` 单路锁源流程保持不变，四根线可以同时保留。Local 按当前界面模式选择生效线路：文本／首尾帧只使用 `driver_audio`，全能参考存在角色输入时只使用 A/B/C；不会让两组音频同时参与同一次生成。
- 连接目标槽已有上传音频时明确拒绝，不自动替换。显示的连接音频不写回 Local 手动上传素材 state。

## 当前时长限制

沿用现有 Local 处理：每段独立参考音频补齐至目标视频帧长，累计预算最多 360 帧（15 秒）。三路参考不能各放 15 秒。

当前整数秒接口：4 秒对应 107 帧（约 4.458 秒），三路累计 321 帧可通过；5 秒对应 124 帧，三路累计 372 帧会拒绝。**三路先用 4 秒视频，每段台词不超过实际帧长**；不自动裁剪、混音或压缩台词。其他参考素材和现有预算检查继续生效。

## 验证

- Python mock：三份采用快照复用、空角色、未采用/过期参数、secret 字段拒绝、固定物理槽、时长与上传冲突、Local graph `reference_only` 分支与旧 `lock_source` 分支。
- 真实 Edge + 隔离 ComfyUI：三卡、共用配置、串行 mock 生成/采用、只更新 B、三槽播放器/标签、@ 插入、工作流刷新、折叠/停用、380/460/560/720/900/1160 宽度。
- 没有调用真实 TTS、LLM、Fal 或视频生成；本轮不能替代多人画面和口型验收。

2026-09-14 验证结果：全量 pytest **821 passed**（原有 pynvml 弃用提示 1 条）。三角色 Edge fixture 执行 5 次 mock 生成，最高并发 1；单人口播和原 driver_audio Edge 回归均通过。截图、宽度数值及 mock 接线工作流位于 `.test-artifacts/multi-speech/`；该工作流仅为测试，不应当作真实生成预设使用。

版本仍为现有 `0.3.1` 开发预览，不提前宣称尚未完成验收的正式版本。
