# HuTX 制作工作台 · 预览 0.3

工作台使用 HuTX 自己的前端代码与现有节点，不包含其它 Studio 项目的源码。入口位于 ComfyUI 侧栏的 **HuTX总台**，顶部「展开」可切换到大工作区。预览 0.3 在镜头列表、逐段队列和本机拼接基础上，增加成片裁剪与声音调整。

## 三个页面

页面提示精简为顶部一行，随页签切换更新；窄侧栏显示在品牌下方，内容区不再重复大标题和说明。

- **角色与声音**：选择已有单人／多角色口播节点，或添加 A/B/C 角色组。执行端、参考声线、预设音色、新台词、生成、试听和采用均复用节点面板。点击「连接到当前镜头三槽音频」将 A/B/C 对应连接到 `reference_audio_1/2/3`，并切换全能参考；如果槽位已经连接其它来源，会拒绝覆盖。
- **镜头生成**：选择已有双引擎或 Local 节点，配置模型、素材、提示词与优化器。缺少生成线路时，可以添加包含 BasicGuider、RandomNoise、SamplerCustomAdvanced、AV Decode、CreateVideo、SaveVideo 的基础单采线路。基础线路使用 24fps；已有完整工作流继续保留原有二采与后处理。
- **成片管理**：从最近 50 条 ComfyUI 历史任务中筛选 HuTX 生成的视频，预览、下载、重新生成当前镜头，选择与排序片段并拼接导出 MP4。

## 镜头列表与逐段生成

1. 在现有面板中配置模型、素材、提示词和已采用口播。需要优化的提示词先在面板里优化，再点击「将当前设置保存为镜头」。每个镜头保存自己的提示词、时长、引擎、素材、口播快照、随机种子和二采／VOSR2 分支开关；其它下游参数共用开始批量生成时的当前画布。
2. 最多保存 32 个镜头，可以改名、调整提示词与时长、排序，或用当前设置更新。修改提示词或时长后，该镜头回到待生成状态。
3. 点击「逐段生成未完成镜头」。它通过原有节点执行快照，每次只提交一段，以独立任务 ID 和指定保存节点收集结果；其它无关保存线路不会一起提交。该入口不会再次调用提示词优化或重新合成已采用的口播。
4. 「停止后续镜头」让当前已提交任务完成，再停止；不会发送全局 interrupt。失败会停止后续提交，已完成镜头保留。网络中断时保留已知任务 ID，再次继续优先检查同一任务，避免重复提交。提交结果未知且没有任务编号时，需先检查 ComfyUI 队列与历史，确认后重新保存该镜头。
5. 使用「按镜头顺序选入成片」，或逐个选择结果，然后进入成片管理。

镜头必须对应一个启用的视频保存节点。线路拓扑改变后要重新保存镜头。项目切换会停止后续提交；已经提交的任务仍由 ComfyUI 完成。请保存工作流以保留快照及已确认的任务记录；关闭页面前尚未保存的状态不保证恢复。

## 成片精修与拼接导出

在成片管理中选取 1–32 段本机视频，按顺序排列后点击「拼接导出 MP4」。单段也可裁剪导出。当前支持相同分辨率、编辑后累计不超过 10 分钟、每个原片不超过 120 秒、最高 4096×2160 像素范围内的视频。不会自动拉伸不同尺寸的画面。

展开片段的 **裁剪与声音**：

- **入点／出点**：以原片秒数设置，入点默认 0，出点留空表示片尾。也可拖动播放器进度后，点击「用当前位置设入点／出点」。至少保留 1/24 秒；最终导出时长向上对齐到 24fps 帧边界，末帧最多补齐不足一帧。
- **播放选段**：从入点开始预览，在出点附近自动暂停；浏览器预览暂停精度取决于媒体事件，导出裁剪由 FFmpeg 执行。
- **音量／静音**：每段独立设置 0–200% 音量或静音。浏览器播放音量最高 100%，超过 100% 的增益在导出时应用；静音与导出设置一致。不会改变已采用的口播或原视频音轨。
- **预计成片**：读取本机视频元数据后汇总裁剪后的时长。文件无法读取、时长未知或裁剪无效会明确显示；后端再次按真实文件校验。更换或移动原文件后应重新选入片段。
- **重置编辑**：恢复该段完整范围、100% 音量和取消静音。编辑参数随工作流保存；无效输入不会写入，需修正后才能导出。

修改片段、顺序或声音后，旧的拼接预览会清除，原成片文件仍保留在输出目录；需重新导出才能得到新版本。拼接任务执行期间锁定片段编辑，可取消任务后再改。这里只做硬切片段精修，不新增连续长口播推理、转场、字幕或多轨时间线。

使用现有 PyAV 与 imageio-ffmpeg，按段同步裁剪画面和音频，统一为 24fps H.264／48kHz 双声道 AAC，对每段单独应用音量，静音段或无声段补静音。每段画面编码一次，最终拼接不再重编码画面。编码为有损处理，最终听感仍需人工试听。

拼接在后台执行，可取消自己的拼接任务，不影响原视频。临时文件结束时清理，成功成片存放于 `ComfyUI/output/video/HuTX_Workbench/`。任务状态保留在服务进程内；服务重启后可重新拼接。已完成文件的引用随工作流保存，可在成片页继续预览下载。

## 同步与执行

工作台使用同一个存活的节点编辑面板。打开页面时面板移入工作台，画布显示「正在 HuTX总台编辑」；切换页面、关闭侧栏或点击返回按钮时原面板归位。不会为同一个角色建立第二套语音控制器。队列运行前须先生成、试听并采用口播。

画布的 DOM Widget 使用固定外壳，工作台只移动内部编辑面板。画布虚拟化、容器卸载或重新挂载不会撤走工作台中的编辑器；旧占位元素丢失时仍可返回并重新接入。同一工作流重载且节点编号不变时，工作台会跟随新的节点实例，不继续编辑已经销毁的旧节点。面板尚未挂在画布上时也可接入，无需先把节点滚动到可见区域。

「运行当前画布」使用 ComfyUI 原队列入口，包括已配置的自动提示词优化。它执行当前画布中的输出线路，不只执行下拉框选中的节点；有多条输出时请检查后提交。工作台中的进度提示来自 ComfyUI 执行事件。

「运行当前画布」按钮正上方居中提供「画面精修」：二采精修与 VOSR2 修脸分别读取和控制本镜头已有的画布开关。Fused Turbo 可关闭以制作初稿，精修时再开启；切换 HyperFlow 按原规则关闭，切回 Fused Turbo 默认开启。手动选择随工作流保存、重新打开时保留。未连接、开关重名导致关联不唯一、已被禁用或受外部输入控制时，控件显示不可用；不新建或改接精修线路。原有二采保留首采音频的线路保持原样。

点击「运行当前画布」，确认 ComfyUI 接受提交后自动打开「成片管理」，并显示底部任务进度；提交校验失败则留在当前页。历史成片使用最大 320 像素宽的预览卡片，保留视频比例，竖屏不裁切。提示词的「恢复原始提示词」「使用优化结果」位于编辑框上方，与历史标签排列，窄窗口自动换行。

运行按钮固定在镜头生成页底部，滚动参数面板时仍可操作。底部任务栏显示排队、当前处理节点、节点步数／百分比、耗时及完成／失败／中断状态；兼容 `progress` 与 `progress_state`。百分比表示当前节点进度，模型加载、解码、修复和保存等没有上报步数的阶段显示处理中；采样达到 100% 后继续等待整个任务完成。任务进度只在界面显示，不写入工作流。切换页面仍可查看当前 ComfyUI 任务，其他任务的迟到结束事件不会覆盖正在运行的任务。

工作台可见时每 3 秒只读核对 `/queue`，任务离开队列后按任务编号读取历史结果；刷新页面或错过 WebSocket 开始事件，也能恢复后端正在执行的任务。恢复任务的计时标为「跟踪」，避免误当作完整执行耗时。连接超时会明确显示无法同步，队列消失但历史未确认时不会假报完成。已有任务排队或执行时，工作台运行按钮暂时禁用，避免重复点入队列；ComfyUI 原生队列入口保持原样。这个核对只读取状态，不提交、取消、重启任务或清理显存。

镜头选择框在宽工作区收窄，模型引擎、时长和保存线路状态显示在同一行右侧，窄侧栏自动换行。口播节点选择框统一显示「HuTX_单角色口播」「HuTX_多角色口播」和节点编号；画布节点标题、类型及接线保持原样。

模型家族、参考视频原声、素材编号、口播时长和三路参考音频的限制继续由原节点与后端校验。工作台没有引入新的推理模型，也不自动下载资源。基础单采线路仍需用户选择与任务匹配的 checkpoint。

## 保存项目

项目名称、镜头快照、任务记录、拼接任务和片段清单（含 `edit.trim_start/trim_end/volume/muted`）存放于当前工作流的 `extra.hutx_workbench`，随 ComfyUI 工作流保存和恢复。预览 0.3 使用 schema 3，兼容读取 schema 1/2，旧片段自动按完整原片、100% 音量、非静音读取。清单最多 100 个视频（单次导出最多 32 个），镜头最多 32 个，快照元数据总量最多 8 MiB；不保存 API Key、音频数据或视频字节。镜头快照含用户提示词和素材引用，分享工作流前应检查这些内容。

「导出片段清单」单独下载元数据 JSON，视频文件需分别下载。生成历史被清除、临时文件过期或文件被移动后，原预览可能失效。重新生成按钮执行的是当前画布设置，不会从旧成片中恢复模型参数。

## 开发验证

```powershell
node --test tests/workbench_state.test.mjs
node --test tests/workbench_sequence.test.mjs
node --test tests/workbench_edit.test.mjs
node --test tests/workbench_progress.test.mjs
node tests/browser_workbench.mjs
```

浏览器测试使用 Playwright 与 Edge，所有语音、提示词、视频队列请求均模拟。可通过 `HUTX_PLAYWRIGHT_MODULE` 指向已安装的 Playwright，`HUTX_TEST_VIDEO` 指向本机 2 秒测试色卡以验证选段播放与时长。`tests/browser_workbench_host.mjs` 用于隔离 ComfyUI 实例的真实节点与前端验证，禁止提交推理和付费服务请求，默认地址为 `127.0.0.1:8190`。

设置 `HUTX_LAYOUT_AUDIT=1` 后，模拟宿主测试会检查 280–1100px 侧栏，以及 390／800／1280／1920px 窗口下的三个页面，共 30 种组合。检查导航与正文对齐、横向溢出、等宽角色卡、混合预设／参考声线时的台词基线、完整角色卡的操作栏、同一行裁剪输入框宽度，并保存截图及几何报告。真实宿主测试同时检查 390／1280px 下角色和双引擎面板；两者均不提交模型推理。长镜头标题、长文件名和长角色名也参与排版检查。

`tests/test_workbench_assembly.py` 使用小型色卡与不同频率的音轨实际编码，检查裁剪区间的画面／音频、25% 音量、静音间隔、顺序、原文件不变和清理。隔离宿主输出目录已有各 0.5 秒的 `api-test-0.mp4`、`api-test-1.mp4` 时，可设置 `HUTX_TEST_ASSEMBLY=1`，由真实前端验证编辑、工作流重载、拼接接口与成片播放。

## 删除成片

成片卡片右侧的「删除」会先显示卡片内确认；点击「确认删除」后永久删除对应的本机视频文件，同时清理当前项目的待拼接引用和镜头结果引用。取消操作不会发送删除请求。删除失败会保留卡片与片段清单；拼接或逐段任务运行时禁用删除。列表刷新时只显示执行历史中仍存在的 HuTX 视频。不会删除整个 ComfyUI 历史任务或同任务的其它输出，也不会删除同名 JSON 等附属文件。后端只接受 HuTX 执行历史中可核对的 output/temp 视频，并校验路径和请求来源。

更新本功能后需重启 ComfyUI 以注册视频管理接口，再强制刷新浏览器。
